## 2. Đã làm

### Must have
- **M1 – Bí mật bị lộ**: JWT secret đang dùng đã khác bản bị lộ. Mật khẩu DB Supabase **chưa đổi** (xem mục 3).
- **M2 – Chống mất thẻ**: trình soạn không mở form khi tải bộ thẻ lỗi (trước đây lưu form trống xoá sạch thẻ và
  lịch sử ôn). Chế độ "Thêm thẻ" chỉ sửa thông tin bộ thẻ khi có thay đổi.
- **M3 – Validate đầu vào**: DTO `@Valid` cho auth và review; họ tên ≤ 100, mật khẩu 6–72 ký tự; hết lỗi báo nhầm
  "Email đã được sử dụng"; lỗi auth trả JSON `{status, error, message}` như các API khác.
- **M4 – Tài liệu**: `SUPABASE_SETUP.md` bỏ SQL tạo bảng tay (xung đột Flyway); README sửa lệnh chạy, biến môi trường.
- **M5 – CI**: `.github/workflows/ci.yml` chạy test backend + lint/build/selfcheck frontend cho mọi push/PR.
- **M6 – "Bộ thẻ của tôi"**: chỉ gồm bộ thẻ sở hữu (kể cả bản đã lưu từ Thư viện) và bộ được chia sẻ qua email.
  Bộ thẻ cộng đồng chỉ ở trang Thư viện.
- **M7 – Quiz đáng tin** (dùng cho xếp hạng): lượt làm do server phát, chấm trên mọi câu đã phát (bỏ trống = sai),
  mỗi lượt nộp 1 lần, hạn giờ 30 giây/câu + 60 giây dự phòng, bỏ dở quá hạn = 0 điểm.

### Should have
- **Chia sẻ thư mục**: mời qua email với quyền xem & học (áp cho cả thư mục con), bật/tắt "ai có link đều xem được",
  mục "Được chia sẻ với tôi". Muốn sửa thì "Lưu bản sao".
- **Quên mật khẩu**: link dùng 1 lần, hết hạn sau 30 phút, trang `/reset-password`.
- **Chặn tạo tài khoản hàng loạt**: 30 tài khoản/giờ/IP; lấy đúng IP thật sau reverse proxy.
- **Dashboard** tự cập nhật số liệu sau mỗi thao tác thêm/sửa/xoá.
- **Phòng thi & Lộ trình** tính từ dữ liệu thật (bỏ 88%, "+3.2%", "Tier A+", giai đoạn viết cứng).
  Số liệu quảng cáo giữ nguyên.
- **Sửa lỗi giao diện**: thư mục bị ép N5, số liệu thư mục con, dấu `\n` khi nhập thẻ, 13 class Tailwind chưa định
  nghĩa, thông báo lỗi ở trang ôn tập và khi thêm nhiều bộ thẻ vào thư mục.
- **Dọn dẹp**: gỡ dependency Redis/WebFlux chưa dùng, xoá `DeckModal` thừa, gom danh sách cấp JLPT về
  `frontend/src/lib/deckUtils.ts`, cập nhật tài liệu trong `docs/`.

### Phát sinh thêm
- Lịch sử quiz trả kèm `deckTitle` (M6 làm bộ thẻ Thư viện hiện "Bộ thẻ không còn tồn tại").
- Endpoint `GET /api/quizzes/{id}/preview` để trang Phòng thi xem câu mẫu mà không mở lượt làm (tránh bị ghi 0 điểm).

## 3. Cần làm ngay

- [ ] **Đổi mật khẩu DB Supabase**: Dashboard → Project Settings → Database → Reset password, rồi cập nhật
      `application-local.properties` của từng thành viên. Không cần viết lại lịch sử git.
- [ ] **Sao lưu DB trước khi chạy backend bản mới**: 3 migration `V4` (chia sẻ thư mục), `V5` (lượt làm quiz),
      `V6` (token đặt lại mật khẩu) sẽ tự chạy trên Supabase ở lần khởi động kế tiếp.
- [ ] **Thử giao diện** trên trình duyệt: trình soạn bộ thẻ, thư mục & chia sẻ, quiz, quên/đặt lại mật khẩu.
- [x] **Commit & push** các thay đổi (`0d90c0f`).
- [ ] **Cấu hình SMTP** để gửi email đặt lại mật khẩu thật: xem [SUPABASE_SETUP.md](../SUPABASE_SETUP.md#5-gửi-email-quên-mật-khẩu-smtp).
      Chưa cấu hình thì link chỉ được ghi vào log backend, đủ dùng khi dev.
- [ ] **Khi triển khai sau proxy có IP public**: đặt `server.tomcat.remoteip.internal-proxies` để lấy đúng IP người dùng.

### API đã đổi (nhánh nào gọi các API này cần cập nhật)

| API | Trước | Bây giờ |
| :--- | :--- | :--- |
| `GET /api/quizzes/{deckId}` | Danh sách câu hỏi | `{attemptId, timeLimitSeconds, questions}` |
| `POST /api/quizzes/{deckId}` | `{answers}` | `{attemptId, answers}` |
| `GET /api/decks` | Gồm cả bộ thẻ public của người khác | Chỉ bộ thẻ sở hữu + được chia sẻ |
| `GET /api/quiz-results` | Không có tên bộ thẻ | Có `deckTitle` |
| `POST /api/auth/register`, lỗi auth | Trả text | Trả JSON |

## 4. Chưa làm (việc sau)

- Khi xem thư mục người khác chia sẻ, số bộ thẻ/số thẻ của thư mục con hiện 0.
- Trang chi tiết bộ thẻ vẫn nháy "đang tải" sau mỗi lần sửa thẻ.
- Còn vài đoạn code trùng lặp nhỏ: thẻ bộ thẻ ở `DecksPage` và `FolderDeckList`, hàm lấy chữ cái đầu tên, hàm làm
  phẳng cây thư mục.
- Chưa có vitest; test frontend mới chỉ gồm `scripts/selfCheck.ts`.
- Theo quyết định của nhóm, để sau:
  - AI (`ai-service` còn mock, chưa xác thực, CORS `*`);
  - Google OAuth, Refresh Token;
  - chuyển JWT khỏi `localStorage` và thêm CSP.
